# 07. Feasibility of the competition — report (in progress)

Question: can a humanizer that preserves meaning and quality get a noticeable score on the crown
detectors? If not, there will be no crowns and the competition will stall.

## Phrasly on all detectors (pilot 1, 78 texts)
`scripts/score_phrasly.py` (quality levels from `scripts/review_phrasly.py`, judges from `configs/gates.json`).
New detector calls only on the Phrasly outputs: GPTZero ~$3, ZeroGPT ~$1.4, Pangram ~$12.

Mean detector score (probability of AI):

| Detector | AI inputs | Phrasly | Humans |
|---|---|---|---|
| GPTZero | 1.00 | **0.94** | 0.00 |
| Pangram | 1.00 | 0.86 | 0.00 |
| ZeroGPT | 0.64 | 0.12 | 0.03 |
| It's AI (not in the crown) | 0.98 | 0.44 | 0.03 |

Score S over the three crown detectors (D-20 with the probability term, D-22 with levels, soft minimum p = −4):

| Submission | AUROC GPTZero / Pangram / ZeroGPT | E_d GPTZero / Pangram / ZeroGPT | S |
|---|---|---|---|
| identity (baseline king) | 1.000 / 1.000 / 0.967 | 0.000 / 0.000 / 0.213 | 0.000 |
| Phrasly with levels (71% severe) | 1.000 / 0.999 / 0.954 | 0.004 / 0.011 / 0.109 | **0.006** |
| Phrasly, G1 only with levels | 1.000 / 0.999 / 0.911 | 0.011 / 0.018 / 0.232 | 0.014 |
| Phrasly without gates | 1.000 / 0.988 / 0.705 | 0.032 / 0.083 / 0.728 | 0.042 |

Crown test against identity (paired bootstrap, B = 2000, n = 78): Phrasly with levels — **crown**
(ΔS = 0.0056, lower bound just above 0, se 0.003); without gates — crown (ΔS = 0.042, lower bound 0.020).

Conclusions:
- **The bottleneck is GPTZero.** A commercial humanizer barely moves it (0.94); the soft minimum hands
  the score to the strictest detector. Pangram moves slightly, ZeroGPT a lot.
- **There is a gradient.** Without the probability term Phrasly would get S = 0 (AUROC GPTZero = 1.000).
  With it, progress is visible and passes the crown test even on 78 texts.
- The next step is our own meaning-preserving reference humanizer: if it moves GPTZero more than Phrasly does,
  the competition is feasible with margin.

## Reference humanizer v1: style transfer + best-of-6 selection (`scripts/ref_humanizer_v1.py`)
A strong LLM (Claude Sonnet 5.5, GPT-6.1 Terra; 3 samples each) rewrites the input in the style of three human texts
of the same genre and length from the pool (texts from the period's human reference set H are not used), preserving facts, order of ideas,
register and paragraphs; of the 6 candidates, the one It's AI considers most human is taken. Costs: OpenRouter ~$5,
GPTZero ~$3, ZeroGPT ~$1.5.

| | Phrasly | Reference v1 |
|---|---|---|
| Quality levels 1 / 0.5 / 0 | 0 / 23 / 55 | **36 / 33 / 9** |
| GPTZero, mean score (AI inputs 1.00) | 0.94 | **1.00** (p_ai = 1.0 for all 78) |
| ZeroGPT (AI inputs 0.64) | 0.12 | 0.55 |
| It's AI (AI inputs 0.98) | 0.44 | 0.84 |
| S on It's AI with levels | 0.042 | 0.050 |

Conclusions:
- The reference's quality is much higher than Phrasly's (the main violation is a register shift toward colloquial, 24
  texts). But **GPTZero does not move at all**: it recognizes any text rewritten by an instruction-tuned LLM with
  confidence 1.0. Phrasly moves it to 0.94 only at the cost of meaning.
- With the soft minimum over detectors, the crown S for such solutions = 0: the competition hinges on GPTZero.
- Open feasibility question: does GPTZero move on text generated by a **non-instruction-tuned** model
  (a base model / a model trained on "back-paraphrasing" toward human texts)? The next step is stage 2.

## Reference humanizer v2: sample submission (2026-11-11)
Owner's decision: train a simple humanizer so that miners have a ready-made submission format
(`examples/ref_humanizer`, README in English). It does not have to be strong.

**How it was made.**
- **"AI → human" pairs.** 1600 pool texts in production proportions (without application) were rewritten
  "as an AI would write it" by the same models, with the same weights, that generate the period inputs. Cost $8.43
  (`scripts/ref_humanizer_v2_pairs.py`).
- **Training.** Qwen3-4B-Instruct-2507 (Apache-2.0), LoRA r = 16 on all linear layers, 2 epochs, 124 steps,
  8.6 min on an H100 PCIe. Eval loss 1.88 → 0.83 (`train/train_lora.py`).
- **Submission.** Merged bf16 weights, transformers 4.57.1 wheels from the harness image, 8.1 GB.
- **Run** in an isolated harness container on the same pod: no network, wheel installation 6 s, 78 outputs
  in 76 s. The whole cycle on Lium: 19 min, **$0.60**; pod deleted (`scripts/ref_humanizer_v2_lium.py`).

**Result on pilot 1** (78 inputs, current gates; judges $1.51, It's AI free):

| | Levels 1 / 0.5 / 0 | It's AI: mean score | S (It's AI) |
|---|---|---|---|
| identity (AI input) | — | 0.983 | 0.008 |
| reference v1 (Sonnet/GPT, best of 6 by It's AI) | 53 / 22 / 3 | 0.844 | 0.050* |
| **reference v2 (4B + LoRA, single pass)** | **36 / 37 / 5** | **0.840** | **0.044** |

\* S of reference v1 was computed with the old levels (36 / 33 / 9).

- Output length is on average ×1.02 of the input (0.89–1.19).
- The main quality loss is "odd words" (25 outputs, level 0.5): the model often swaps words mechanically.
  Another 6 are a change of person/tense, 8 are a distorted fact (G1).
- On It's AI, v2 nearly catches up with v1, although v1 is several times more expensive per text (6 calls to strong LLMs and selection by a detector).
  AUROC against humans is still 1.0: every output looks "more AI" than the humans in the same group.
- v2 has not been scored on the paid detectors. Pangram costs ~$11 per 78 texts. GPTZero and ZeroGPT are waiting for a top-up.
